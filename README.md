# 映译 YingYi

Windows 电影字幕翻译与视频处理工具。为抖音电影切片场景设计：双语字幕烧录、打码、倒计时、滤镜、切段，一条龙处理。

## 功能

- **双语字幕烧录**：提取内嵌字幕轨或加载 .srt 文件，AI 翻译（支持 35 种源语言、19 种目标语言），英文在下方、中文在上方，字号颜色可调
- **打码**：整屏模糊 / 框选局部模糊（画面上拖框），强度三档，时间前后可调
- **去水印**：框选台标、logo，全片智能抹除
- **前方高能倒计时**：指定时刻前画面左下角显示 3-2-1 红色大字
- **滤镜**：去血色（柔和/强力）、黑白，按时间段生效
- **切段**：自动均分或手动切点，切口精确到帧
- **播放器**：倍速、逐帧定位、时间跳转、位置记忆
- **硬件加速**：Intel QSV / NVIDIA NVENC / AMD AMF 自动检测
- **HDR 转换**：HDR 片源自动色彩转换，画面不发灰
- **中断恢复**：压制中断后重开自动复用上次成品（设置未变时）

## 下载

见 [Releases](https://github.com/sxczry-dot/yingyi/releases) 的绿色包：解压后双击 `映译.exe` 即可，整个文件夹可拷到任意 Windows 11 电脑直接使用（无需安装任何环境）。

## 使用

1. 打开电影（mp4 / mkv 等）→ 自动检测内嵌字幕，或手动选择 .srt
2. 设置里填 DeepSeek API Key → 字幕页选语言 → 翻译
3. 打码页 / 倒计时页 / 滤镜页 / 切段页按需设置
4. 导出 → 成片输出到电影旁的「电影名_导出」文件夹，完成后自动打开

## 项目结构

```
app.py            程序入口（pywebview 窗口 + 业务接口）
core/             核心逻辑（ffmpeg 封装、翻译、字幕、任务编排）
web/              界面（HTML/CSS/JS）
```

## 技术栈

Python + pywebview + FFmpeg + DeepSeek API，PyInstaller 打包单文件 exe。
